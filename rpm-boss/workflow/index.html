rpm-boss - workflow docs

Part of how I build software with LLMs.

The complete, real workflow documentation behind rpm-boss (engine RPM from sound - live demo): every PRD, design doc, task list, review checklist and decision discussion, per feature, as they were written during development. Published as-is, lightly scrubbed of private details. One snapshot commit; the living copy is private.

  • mvp.md - leading document: scope, UI, stack, done-criteria.
  • workflow.md - stage-gated execution, layout, commit rules.
  • backlog.md - post-MVP ideas.
  • mvp/<N>-<feature>/ - per-feature prd / design / tasks / review.
  • discussions/ - dated decision notes: 2026-09-10 audio-input scope, 2026-09-10 Android microphone capture, 2026-09-10 i18n languages and markets, 2026-09-14 realtime-tacho requirements, 2026-09-14 tacho layout and viz libs, 2026-09-14 tacho range and detection limits.

How to read this

New here? Take one feature end to end:

  1. workflow.md - the stages and gates every feature passes through.
  2. mvp/3-waveform-crop/ - a full run: prd (what and why), design (how), tasks (ordered steps), review (verification checklist and findings).
  3. discussions/2026-09-10-audio-input-scope.md - how scope decisions get made before a PRD exists.
